# DSA Codes 🚀

A personal collection of **Data Structures and Algorithms (DSA) implementations in C++**. This repository documents my learning journey through core DSA concepts, hands-on coding, debugging, and problem-solving.

The goal is to understand how data structures work internally—not just use them—and to improve logic one implementation at a time.

> **Code. Understand. Debug. Improve.**

## 📚 Topics Covered

The repository is a work in progress. Implementations and practice programs are organized around topics such as:

| Topic | Concepts |
|---|---|
| **Arrays** | Array operations and problem-solving |
| **Searching** | Linear search and binary search |
| **Sorting** | Basic sorting techniques, merge sort, and quick sort |
| **Linked Lists** | Node-based implementation and linked-list operations |
| **Stacks** | Stack operations and expression-related problems |
| **Queues** | FIFO queue implementation and operations |
| **Trees** | Binary trees, Binary Search Trees (BST), and tree traversals |

More concepts and practice problems will be added as I continue learning.

## ▶️ How to Compile and Run

Make sure a C++ compiler is installed and available in your terminal.

1. Clone the repository:

   ```bash
   git clone https://github.com/argavthakur-maker/DSA_CODES.git
   ```

2. Open the repository folder:

   ```bash
   cd DSA_CODES
   ```

3. Navigate to the folder containing the program you want to run.

4. Compile a C++ file:

   ```bash
   g++ filename.cpp -o program.exe
   ```

5. Run it on Windows:

   ```powershell
   .\program.exe
   ```

   On Linux or macOS:

   ```bash
   ./program
   ```

Replace filename.cpp with the actual source-file name.
